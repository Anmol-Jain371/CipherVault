# Change Log

All notable changes to the "CipherVault" extension will be documented in this file.

## [0.1.1] - 2026-10-17

- **Rebranding:** Extension rebranded as **CipherVault** (*Secure. Encrypted. Remote.*).
- **New Minimal Icon:** Added new minimal, high-contrast dark navy icon with clean white lock and vibrant blue keyhole.
- **Marketplace Compatibility:** Category aligned to official Visual Studio Code Marketplace taxonomy.
- **Backward Compatibility:** All existing commands, configuration keys (`personalVault.serverUrl`), and storage protocols remain 100% backward-compatible.

## [0.1.0] - 2026-10-17

- Initial release with strictly read-only remote access, in-memory credential storage, and local export capabilities.
